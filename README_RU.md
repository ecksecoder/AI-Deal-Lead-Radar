Промышленная асинхронная система мониторинга сделок, сбора лидов и нейросетевого скоринга релевантности для фриланс-бирж, тендерных площадок и B2B-агрегаторов. Оснащена интерактивной панелью управления в Telegram (aiogram 3.x), движком дедупликации на базе SQLite WAL, полной трехъязычной локализацией (EN/UK/RU) и автоматизированным формированием отчетов в формате CSV с маркером последовательности байтов UTF-8 (BOM).

---

## Архитектура системы

```
+-----------------------------------------------------------+
| Целевые веб-источники и RSS-ленты                         |
+-----------------------------------------------------------+
                              |
                              v
+-----------------------------------------------------------+
| Асинхронный воркер опроса                                 |
| (aiohttp, feedparser, санитизация DOM, защита от SSRF)    |
+-----------------------------------------------------------+
                              |
                              v
+-----------------------------------------------------------+
| Слой дедупликации по хешам содержимого                    |
| (детерминированные сигнатуры SHA-256 в режиме SQLite WAL) |
+-----------------------------------------------------------+
                              |
                              v
+-----------------------------------------------------------+
| Движок скоринга релевантности                             |
| (нормализованная матрица ключей, кросс-языковой анализ)   |
+-----------------------------------------------------------+
                              |
                              v
+-----------------------------------------------------------+
| Диспетчер (маршрутизатор aiogram 3.x)                     |
+-----------------------------------------------------------+
                              |
              +---------------+---------------+
              |                               |
              v                               v
+-------------------------------+ +-------------------------------+
| Мгновенные алерты в Telegram  | | Генерация экспорта            |
| (инлайн-действия Micro-CRM)   | | (Excel-совместимый CSV / BOM) |
+-------------------------------+ +-------------------------------+
```

Последовательность конвейера обработки данных:
Target Web Sources & RSS -> Asynchronous Polling Worker (aiohttp, feedparser, DOM sanitization) -> Content Hash Deduplication Layer (SHA-256 in SQLite WAL) -> Relevance Scoring Engine (Normalized keyword matrix and AI score filter) -> Dispatcher -> In-Telegram Instant Alerts & Export Generation (CSV/XLSX).

## Функциональные возможности

- Автономный фоновый сбор данных: Асинхронный фоновый воркер производит периодический опрос сконфигурированных RSS/Atom лент, HTML-листингов и JSON-эндпоинтов с экспоненциальной задержкой повторов (backoff) и валидацией адресов против атак SSRF.
- Хеширование с гарантией отсутствия дубликатов: Детерминированный цифровой отпечаток SHA-256 (вычисляемый по нормализованным строкам URL и заголовка) исключает повторную обработку записей и предотвращает дублирование уведомлений.
- Трехъязычный интерфейс (GB/UA/RU): Полная поддержка английского, украинского и русского языков. Автоматическое определение локали клиента Telegram комбинируется с возможностью ручного переключения в реальном времени через инлайн-клавиатуру.
- Строгие стандарты онбординга: При первом запуске пользователями без сохраненной записи в базе данных активируется приветственный экран выбора языка с латинским обозначением синхронизации '(Telegram)'.
- Изоляция форматирования уведомлений по подписчикам: Фоновый планировщик извлекает персональные языковые настройки каждого подписчика, генерируя карточки лидов, бейджи приоритета и инлайн-кнопки строго на языке адресата.
- Динамический локализованный экспорт в CSV/Excel: Формирование отчетов с кодировкой UTF-8-SIG (префикс BOM) и разделителем "точка с запятой", динамически переводящее названия колонок (ID, Date, Source, Category, Score, Title, Summary, Status, URL) на язык текущего пользователя.
- Синтетический демонстрационный движок: Встроенный генератор реалистичных B2B-проектов, полностью локализованный для английского, украинского и русского языков, предназначенный для сквозного тестирования функционала без сетевых обращений.

## Стек технологий

| Компонент | Технология | Назначение в архитектуре |
|---|---|---|
| Язык программирования | Python 3.10+ | Основная среда выполнения асинхронного приложения |
| Фреймворк бота | aiogram 3.x | Интеграция с Telegram Bot API, FSM-сценарии и обработка событий |
| База данных | SQLite 3 (режим WAL) | Хранение состояния, настроек пользователей, источников и индексов SHA-256 |

| Модуль AI-скоринга | Google Gemini SDK (`google-genai`) | Семантическая оценка предложений и кросс-языковой анализ релевантности |
| Эвристический скорер | Движок регулярных выражений Python | Детерминированный анализ плотности ключевых слов, бюджетов и срочности |
| Экспорт отчетов | Модуль `csv` Python | Генерация табличных файлов с префиксом BOM (`\xef\xbb\xbf`) для Microsoft Excel |

## Установка и настройка

### Переменные окружения

Конфигурация параметров системы осуществляется через файл `.env`:

| Переменная | Тип | Значение по умолчанию | Описание |
|---|---|---|---|
| `BOT_TOKEN` | Строка | Отсутствует (Обязательно) | Токен доступа Telegram Bot API, полученный у @BotFather. |
| `CHECK_INTERVAL_SECONDS` | Целое число | `300` | Интервал опроса фонового сборщика в секундах. |
| `DEFAULT_SCORE_THRESHOLD` | Целое число | `60` | Минимальный балл релевантности (0-100) для отправки алерта. |
| `DB_PATH` | Строка | `radar_state.db` | Путь к файлу базы данных SQLite в режиме WAL. |
| `ADMIN_IDS` | Список целых через запятую | Отсутствует | Идентификаторы Telegram-аккаунтов с доступом к системе (RBAC). |
| `GEMINI_API_KEY` | Строка | Отсутствует (Опционально) | API-ключ Google Gemini. При отсутствии используется эвристический скоринг. |
| `GEMINI_MODEL` | Строка | `gemini-3.8-flash` | Модель Gemini для инференса и текстовой аналитики. |
| `HTTP_TIMEOUT` | Вещественное число | `15.0` | Предельное время ожидания сетевых ответов в секундах. |
| `EXPORT_DIR` | Строка | `exports` | Директория временного размещения сгенерированных отчетов. |

### Порядок установки

1. Клонирование репозитория и создание виртуального окружения:
```bash
git clone <repository_url>
cd project_3
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
```

2. Установка зависимостей:
```bash
pip install -r requirements.txt
```

3. Конфигурация параметров:
```bash
cp .env.example .env
# Заполните переменные в файле .env
```

4. Запуск приложения:
```bash
python bot.py
```
